## 两次真实图纸实验 / Two real-map cases

本页记录两个深圳行政区划图案例。两例均使用市级参考边界（EPSG:3857），拟合残差在当地米制投影中测量。原始 EPS、参考 GPKG 与完整运行目录不随仓库分发；本 skill 的统一入口重跑统计口径见[实验记录](experiments.md)。

### 深圳区级图（Qoder）

- 输入：700 × 500 mm 的深圳市行政区划 EPS；参考为深圳市界，多部件、无区界属性。
- 提取：17 条浅彩色填充路径经合并得到 10 个区面，10/10 区名由图面 200 dpi 裁片判读，面积与位置仅作旁证。
- 一个相似变换作用于全部区面：48.7164 m/pt，约 1:138,094；图纸标称 1:119,900，低估约 15.2%。
- Mode R：与参考市界对称差 13.650 km²；源→参考中位轮廓距离 12.68 m，P90 72.84 m。局部海岸概化造成差异，不能把它全归为配准误差。
- Mode C：与参考市界对称差 0 m²；补入 8.4833 km²、裁去 5.1697 km²；七条贴合断言通过，内部区界仍在图纸源线上。补入的每块区域有证据类别，但新增面积并非图纸直接证据。
- 交付原先有 13 个文件及 15 个重跑日志，整理为 8 个文件。历史命名不同于当前默认契约，需要按历史清单检查，不能因此判定几何失败。
- **未验证**：参考数据没有区级边界，市界拟合和 Mode C 贴合都不能证明每条区内接缝准确。

证据：本地运行生成的 QC JSON、日志与 GeoPackage。源文件未随仓库分发；这里保留案例统计与复核边界，不提供原始交付包。

### 罗湖街道图（ZCode，GLM-5.3-Flash）

- 输入：420 × 297 mm 的《深圳市罗湖区》EPS；转换后有 6472 条矢量路径、8 个小图像，原生文字为零，图面文字已转曲。EPS 里有“福田区”旧标题字符串，图面主体实际是罗湖。
- 提取：8 种浅彩色对应 10 个街道面；邻区灰面、道路、水、文字轮廓和装饰被排除。同色不等于同一街道。
- 地名：整页 300 dpi OCR 得 131 条标注；漏掉的“南湖”经定向裁片补录；“清水河口”“问翠竹”等噪声经复核。10/10 街道名来自图面标注，并通过标注点与面包含关系关联。132 是全部标注条数，**不是街道名条数**。
- 参考只有全市外界。初始粗评分把罗湖的一段误对到大鹏湾；经罗湖桥与大梧桐两个经核实的地标定位正确盆地，最终只用深港界河段拟合。连续匹配段约 14.08 km，源→参考中位残差 10.93 m、P90 26.70 m。
- 最终相似变换 16.343 m/pt，约 1:46,300；图注与图上比例尺条均约 1:30,000，不能据此固定几何尺度。罗湖区配准后面积 78.88 km²，与外部约 78.75 km² 接近，属于旁证。
- Mode R 交付 4 个文件、一个 GPKG 中有 5 层，历史清单检查通过。参考没有罗湖区同级面，不能运行以全市面为目标的 Mode C。
- **未验证**：约 73.2% 的源轮廓不在市级参考的拟合弧段，内部街道界线也无同级独立参考。

证据：本地运行生成的 QC JSON、日志与 GeoPackage。源文件和交互记录未随仓库分发。历史报告中的比例尺换算存在矛盾；本页采用由 16.343 m/pt 计算得到的约 1:46,300。拟合器内部残差与交付几何回读的距离是不同统计对象，应分别标注。

### 可迁移的改进 / Transferable changes

1. 先判定完整或局部覆盖，再选择轮廓匹配与 C 模式；局部用连续共线段和可信地标破除伪盆地。
2. 从本张图的路径/颜色普查推导填充筛选；同色拆多面，先确认矢量保留再配准。
3. 区与街道都走图面地名管线：原生文字 → OCR → 仅歧义裁片复核；名称证据与几何同交付。
4. 以交付文件回读生成报告，给比例尺和统计口径做可计算断言；保留源几何 R，只有同范围才允许 C。
