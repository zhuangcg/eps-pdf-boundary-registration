## 配准方法与适用范围

### 1. 页面坐标与参考坐标

EPS 经 Ghostscript 保留矢量转换为 PDF；PDF 路径在页面点坐标系中，Y 轴通常向下。参考 GPKG 必须有 CRS。若未指定 `reference.fit_crs`，小范围自动估计当地 UTM，更宽范围以参考中心建立米制等距方位投影；显式指定时必须是米制投影。交付再转回参考 GPKG 的 CRS。不会给页面点直接赋投影。

### 2. 行政面候选

填充路径按页面几何、颜色和尺寸构成候选。自动模式保留每条原始填充路径的边界，以免相邻同色面合并；显式复核的 `keep_colours_rgb` 和 `split_colours_rgb` 只适用于当前图。描边按 RGB、宽度和虚线分组，使用闭合网络面化；需要手动补接时必须明确页面点容差，所有端点桥写入 QC。两个可信候选并存时暂停并检查原图。提取出的 `page_units.gpkg` 无 CRS，仅是中间结果。

面积占凸包不到 10%、且达到页面最小尺寸的填充路径会标为色带候选。目标行政填色与色带并存而未复核颜色时暂停；确认填色后以填色面的边界为准，并在 QC 中记录被排除的色带 drawing。只有单个封闭色带具有唯一内环且没有其他行政填色候选时才自动使用该内环；单环开放色带没有可直接取出的“内环”，必须复核。自接触填充环仅在修复后仍为单面且面积不变时修复。

同色小岛仅在只有一个候选主体面时并入该面；有多个可能主体面时返回 `REVIEW_EXTRACTION`，不再用最近距离决定归属。跨颜色、跨多个路径的离岛归属仍须人工核对，不能仅凭填色和距离证明行政归属。

### 3. 完整同范围

使用源图行政面并集和参考面的最大连续外轮廓。由两者面积比估计初始尺度，测试旋转及反射；双向采样距离筛粗候选，再对所有不同的初始变换执行修剪 ICP 相似配准。仅在中位距离改善超过 `model_selection.escalate_to_affine_if_median_gain_gt`（默认 0.20）且尺度各向异性低于 0.05 时选仿射。源图可能有孤岛/飞地；当前拟合主轮廓，所有面仍使用同一矩阵，岛屿位置和内部界线应单独核看。

交付前再用**完整**源图/参考多面检查：IoU 至少 0.95，按各连通片边长加权的双向轮廓 P90 均不超过参考面积等效半径的 1%，且无另一个明显不同但同样可信的变换。复验采样间距随参考范围缩小，避免小范围地图的固定 25 m 采样间隔造成虚假残差。任一项未过即 `REVIEW_REGISTRATION`，在 work 目录保留候选叠加图而不写最终 GPKG。这只是保守的自动放行条件，不是地图精度承诺；范围确认不覆盖它。

### 4. 可信共同弧段

当前入口要求两处经过核实的 `landmarks` 作为初始化，随后在参考轮廓上以最近邻互检、逐级缩小的 400/250/150 m 门限和修剪相似 ICP 拟合。只有至少 1 km 且连续的共同弧段可以作为有效结果。地标不替代最终边界拟合；没有可信种子时返回 `REVIEW_REGISTRATION`。当前没有自动在整个国界上任意搜索局部城市位置，以防把河岸/海岸误配到另一处形似弧段。

### 5. 无共同边界与 Mode C

若源图是内陆局部范围、参考只有上级国界/市界，外轮廓没有共同弧段，则无法仅靠上级外轮廓确定源图位置。程序可以先读取图面供检查，但会在配准前返回 `NO_COMMON_BOUNDARY`，不写最终 GPKG；仅提供两个定位点也不会让当前无共同边界流程继续。只有 `same_extent` 可请求 Mode C：生成 Mode R 后在临时目录把外轮廓约束到参考面，并以面积、覆盖和接缝断言检验；参考补面没有唯一相邻源图面时返回 `REVIEW_CONFORMANCE`。全部通过后才交付，Mode C 新增的参考面积不是原 EPS/PDF 的证据。

### 6. 解释限制

全局变换保持各行政面的相对几何，但参考外界不能验证内部行政界线。城市尺度或国家尺度的拓扑可能包含多片、多洞和概化差异；当前自动配准应视为候选，需读 `qc.json` 和 `overlay.png`，不能只看 IoU。历史案例数值不是通过门槛。实施细节与实际 QC 字段见 [implementation-notes.md](implementation-notes.md) 与 [qc-spec.md](qc-spec.md)。
